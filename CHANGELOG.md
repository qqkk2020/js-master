# Changelog

All notable changes to the **JSMaster** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-21
### Added
- Complete interactive JavaScript quiz trainer with 4 core curriculum topics.
- Modular ES6+ architecture (api.js, state.js, quiz.js, theory.js, topics.js, ui.js).
- Full suite of Vitest unit tests verifying edge cases and business logic.
- Automated CI pipeline via GitHub Actions and live deployment on GitHub Pages.
- Project documentation (requirements, architecture, UI/UX, AI log, bug reports, user guide, pitch deck, retrospective).
