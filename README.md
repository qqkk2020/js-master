# JSMaster — Інтерактивний навчальний тренажер із JavaScript

Розроблено в рамках навчальної дисципліни «Командна розробка програмних проєктів» (КРПП) студентом спеціальності 014.09 Середня освіта (Інформатика).

- **Команда:** ScriptCrafters
- **Розробник / QA:** Ященко Єгор, група СОІ-23-1
- **Мета проєкту:** Створення доступного браузерного інструменту для формування базової алгоритмічної грамотності та вивчення сучасного стандарту JavaScript (ES6+) учнями 8–9 класів.
- **Опублікований застосунок:** [https://qqkk2020.github.io/js-master/](https://qqkk2020.github.io/js-master/)

## Стек технологій
- **Мова:** JavaScript (ES6+ модулі, async/await, стрілкові функції)
- **Інтерфейс:** Семантичний HTML5, Flexbox/Grid CSS3 з підтримкою доступності WCAG AA
- **Тестування:** Фреймворк Vitest (Unit-тести бізнес-логіки)
- **CI/CD:** GitHub Actions (автоматизований прогін тестів та деплой на GitHub Pages)
