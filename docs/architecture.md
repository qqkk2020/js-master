# Архітектурна специфікація системи «JSMaster»

## 1. Архітектурний підхід
Проєкт побудовано за принципом клієнтського модульного моноліту з використанням нативних модулів ECMAScript 6 (ES Modules).

## 2. Структура модулів
- `app.js` — Головний координатор життєвого циклу застосунку, маршрутизації екранів та обробки подій.
- `state.js` — Менеджер стану з підтримкою синхронізації з LocalStorage (збереження прогресу та балів).
- `topics.js` — Модуль асинхронного завантаження навчального контенту з підтримкою локального резерву.
- `theory.js` — Модуль динамічної генерації розмітки теоретичного конспекту.
- `quiz.js` — Ізольований движок бізнес-логіки (перевірка відповідей, розрахунок відсотків, чисті функції для тестування).
- `api.js` — Асинхронний REST-клієнт для взаємодії із зовнішніми джерелами даних.
- `ui.js` — Утиліти маніпуляції DOM-деревом та керування відображенням екранів.
