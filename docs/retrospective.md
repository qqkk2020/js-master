# Протокол командної ретроспективи проєкту «JSMaster» (Start, Stop, Continue)

## 1. Загальний огляд
Команда ScriptCrafters підбила підсумки повного циклу розробки тренажера за методологією Scrum.

## 2. Категорії ретроспективи:
- **START (Почати):** Писати більше E2E тестів для перевірки поведінки інтерфейсу користувача.
- **STOP (Припинити):** Робити великі неатомарні коміти, залишати написання технічної документації на останній день.
- **CONTINUE (Продовжити):** Регулярні код-рев'ю, Feature Branch Workflow, повна автоматизація CI в GitHub Actions.
