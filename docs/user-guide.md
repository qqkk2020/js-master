# Інструкція користувача навчального тренажера «JSMaster»

## 1. Загальні відомості
Тренажер «JSMaster» створений для комфортного та наочного вивчення основ JavaScript (ES6+). Застосунок працює повністю онлайн у будь-якому сучасному браузері.

## 2. Покроковий алгоритм роботи
1. Відкрийте офіційне посилання на сайт: https://qqkk2020.github.io/js-master/.
2. Оберіть навчальну тему в каталозі («Змінні let/const», «Стрілкові функції», «Методи масивів», «DOM та асинхронність»).
3. Ознайомтеся з коротким теоретичним конспектом та натисніть «Почати тестування →».
4. Оберіть правильний варіант відповіді для кожного завдання та отримайте миттєву оцінку.
5. Перегляньте фінальний результат успішності та поверніться до каталогу.
