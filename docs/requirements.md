# Специфікація вимог до навчального тренажера «JSMaster»

## 1. Загальний опис системи
Навчальний тренажер «JSMaster» створений для наочного, доступного та інтерактивного засвоєння синтаксису сучасної мови програмування JavaScript (стандарт ES6+) учнями 8–9 класів та студентами коледжів. Застосунок функціонує безпосередньо у браузері без необхідності встановлення стороннього ПЗ чи налаштування середовищ.

## 2. Функціональні вимоги (Functional Requirements)
- **FR-01:** Каталог із 4 ключових тем («Змінні let та const», «Стрілкові функції», «Методи масивів», «DOM та асинхронність»).
- **FR-02:** Теоретичний конспект із форматованими блоками коду та акцентом на типові помилки початківців.
- **FR-03:** Інтерактивний тест із 4 варіантами відповідей, миттєвим колірним зворотним зв'язком та поясненням правил.
- **FR-04:** Збереження та накопичення результатів тестування у localStorage браузера з відмітками успішності в каталозі.
- **FR-05:** Відмовостійка робота в автономному режимі Offline із використанням вбудованих fallback-даних.

## 3. Нефункціональні вимоги (Non-Functional Requirements)
- **NFR-01 (Продуктивність):** Час початкового завантаження сторінки до 1.5 секунди за нормального з'єднання.
- **NFR-02 (Адаптивність):** Коректне відображення та збереження функціоналу на екранах від 360px до 4K.
- **NFR-03 (Доступність):** Контрастність тексту за стандартом WCAG AA (коефіцієнт не менше 4.5:1).
- **NFR-04 (Надійність):** Обробка виняткових ситуацій (відсутність інтернет-з'єднання, помилки мережі) через блоки try...catch.

## 4. Пріоритизація вимог за методом MoSCoW
| ID | Вимога | Пріоритет за MoSCoW |
|:---|:---|:---|
| US-01 | Навігація каталогом навчальних модулів JavaScript | Must have |
| US-02 | Читання теоретичного конспекту з прикладами коду | Must have |
| US-03 | Проходження інтерактивного тесту з миттєвою перевіркою | Must have |
| US-04 | Збереження відсотка успішності у браузері | Should have |
| US-05 | Автономний режим роботи без інтернет-з'єднання | Should have |
| US-06 | Щоденні мотиваційні поради через відкритий REST API | Could have |
