# Специфікація інтерфейсу користувача та UI/UX гайдлайн «JSMaster»

## 1. Колірна палітра (Design System)
- **Фон сторінки:** Глибокий сланцевий колір `#0F172A`
- **Фон карток:** Темно-синій `#1E293B`
- **Основний акцент (Brand Gold):** Золотисто-жовтий колір JavaScript `#F59E0B` (Hover: `#D97706`)
- **Статус успіху:** Смарагдово-зелений `#10B981` (Фон: `rgba(16, 185, 129, 0.15)`)
- **Статус помилки:** Рубіново-червоний `#EF4444` (Фон: `rgba(239, 68, 68, 0.15)`)
- **Основний текст:** `#F8FAFC`
- **Вторинний текст:** `#94A3B8`

## 2. Інтерфейсні стани компонентів
- Картки тем мають ефект плавного підйому `transform: translateY(-2px)` при наведенні.
- Варіанти відповідей мають велику площу кліку (padding 14px), адаптивні для мобільних пристроїв.
- Миттєвий візуальний зворотний зв'язок з підсвічуванням правильних і хибних варіантів.
