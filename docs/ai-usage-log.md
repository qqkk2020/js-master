# Журнал використання генеративного ШІ у проєкті «JSMaster»

## 1. Запит (Prompt)
Сформульовано інженерний промпт для розробки асинхронного REST API клієнта з підтримкою автономного режиму.

```text
Роль: Senior JavaScript Developer.
Завдання: Напиши модуль api.js для навчального веб-тренажера з мови JavaScript «JSMaster».
Вимоги:
1. Асинхронний запит через fetch() з async/await до публічного API щоденних порад для програмістів.
2. Обробка помилок мережі у блоці try...catch.
3. Обов'язковий локальний резервний об'єкт FALLBACK_TIP на випадок збою з'єднання.
4. Додай прапорець isFallback для індикації джерела даних в інтерфейсі.
5. Використай параметр { cache: 'no-store' } для уникнення застарілого кешу.
```

## 2. Результат інспекції та верифікації
- ШІ згенерував базову функцію `fetchDailyTip()`.
- Внесено ручну правку: адаптовано структуру даних для сумісності з UI-банером застосунку.
- Проведено тестування в режимі Offline вкладки DevTools Network. Модуль бездоганно повертає локальний fallback без помилок у консолі браузера.
