# Реєстр виявлених та виправлених дефектів проєкту «JSMaster»

## 1. BUG-01: Чутливість до випадкових пробілів у відповідях
- **Серйозність:** Medium
- **Опис:** Функція перевірки повертала false, якщо рядок містив кінцеві пробіли.
- **Виправлення:** Додано виклики `.trim().toLowerCase()` у чистій функції `validateAnswer()`.

## 2. BUG-02: Можливість повторного кліку на варіанти відповідей
- **Серйозність:** High
- **Опис:** Користувач міг повторно натискати кнопки після завершення перевірки поточного запитання.
- **Виправлення:** Впроваджено циклічне блокування кнопок `btn.disabled = true` одразу після вибору.
