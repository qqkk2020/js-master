# Регламентний сценарій пітчу проєкту «JSMaster» на Demo Day (5–7 хвилин)

## Слайд 1. Вступ та актуальність (1 хв)
- Представлення команди ScriptCrafters (Ященко Єгор, група СОІ-23-1).
- Актуальність: полегшення вивчення першої текстової мови програмування для школярів через практичні мікро-вправи.

## Слайд 2. Рішення — веб-тренажер JSMaster (1 хв)
- Робота у браузері без встановлення Node.js та складних налаштувань.
- Наочні конспекти та інтерактивна перевірка знань за секунди.

## Слайд 3. Жива демонстрація (Live Demo) (2 хв)
- Демонстрація сайту https://qqkk2020.github.io/js-master/.
- Проходження тесту з підсвічуванням правильних відповідей та збереженням у LocalStorage.

## Слайд 4. Інженерні стандарти (1.5 хв)
- Модульний JS, чисті функції, модульні тести Vitest, CI/CD конвеєр у GitHub Actions.
